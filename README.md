## 🌟 What is IPlay?

<div align="center">

**IPlay is India's first gamified mobile learning platform for Intellectual Property Rights education.**

Transform complex legal concepts into an exciting adventure with **6 interactive realms**, **7 action-packed games**, **35+ collectible badges**, and a comprehensive learning system designed specifically for Indian students.

</div>

### 🎯 The Problem We're Solving

In today's innovation-driven economy, understanding IP rights is crucial for every student, entrepreneur, and creator. Yet:

- 📚 **IPR education is boring**: Traditional textbooks make legal concepts feel dry and inaccessible
- 🎓 **Limited curriculum integration**: Most schools don't teach IPR systematically
- 💰 **Expensive courses**: Quality IPR education is often behind paywalls
- 🌍 **Lack of practical knowledge**: Students learn theory but can't apply it to real-world scenarios
- 😴 **Low engagement**: Legal topics struggle to compete with social media and games

### 💡 Our Solution

IPlay transforms IPR education through:

- 🎮 **Gamification**: Turn learning into an addictive game with XP, badges, and leaderboards
- 🎯 **Interactive Content**: 7 engaging games that make concepts stick
- 📚 **Comprehensive Curriculum**: 6 realms covering all aspects of IPR in India
- 🏫 **School Integration**: Tools for teachers to assign, track, and grade
- 🆓 **Free Forever**: No subscriptions, no ads, no hidden costs
- 📱 **Mobile-First**: Learn anytime, anywhere, even offline

## 🎯 The Six IPR Realms

Embark on an epic journey through six distinct realms, each dedicated to a crucial aspect of Intellectual Property Rights. Master them all to become an IPR Champion!

<div align="center">

### 📚 Realm 1: Copyright Kingdom

<img src="assets/logos/copyright_logo.png" alt="Copyright Logo" width="120"/>

**Protect Creative Expressions**

</div>

Dive into the world of creative works and learn how artists, authors, musicians, and creators protect their original expressions. From books and songs to software and films, discover the power of copyright law.

**What You'll Learn:**
- 📖 Literary works protection (books, poems, articles)
- 🎵 Musical compositions and sound recordings
- 🎬 Cinematographic films and videos
- 💻 Software and digital content rights
- 🎨 Artistic works and visual creations
- ⏰ Duration of copyright (lifetime + 60 years)
- 🔄 Fair use and exceptions
- 🌍 International copyright treaties

**Real-World Applications:** Understanding YouTube copyright claims, music licensing, book publishing rights, software piracy prevention

---

<div align="center">

### 🏷️ Realm 2: Trademark Territory

<img src="assets/logos/trademark_logo.png" alt="Trademark Logo" width="120"/>

**Guard Brand Identity**

</div>

Enter the competitive world of brands and logos! Learn how companies protect their identity, prevent confusion, and build trust with consumers through trademark registration and enforcement.

**What You'll Learn:**
- 🎯 What qualifies as a trademark (logos, names, slogans)
- ✅ Registration process and requirements
- 🔍 Trademark search and clearance
- ⚖️ Infringement and passing off
- 🛡️ Famous marks and well-known trademarks
- 🔄 Renewal and maintenance
- 🌐 Madrid Protocol for international protection
- 🚫 Generic marks and loss of distinctiveness

**Real-World Applications:** Recognizing fake products, understanding brand protection, logo design considerations, domain name disputes

**Featured Brands:** Nike, Adidas, Coca-Cola, Apple, Google, Amazon, Tata, Amul, and 20+ more Indian and international brands!

---

<div align="center">

### 🔬 Realm 3: Patent Palace

<img src="assets/logos/patent_logo.png" alt="Patent Logo" width="120"/>

**Secure Innovations**

</div>

Step into the laboratory of innovation! Discover how inventors protect their groundbreaking ideas, from life-saving medicines to revolutionary technologies. Learn the patent system that drives global innovation.

**What You'll Learn:**
- 💡 Patentability criteria (novelty, inventive step, industrial application)
- 📝 Patent application process and documentation
- 🔬 Types of patents (utility, design, plant)
- ⏳ Patent term (20 years from filing)
- 🔓 Patent disclosure and claims
- 🌍 International patent systems (PCT, Paris Convention)
- ⚖️ Patent infringement and litigation
- 🚫 Exceptions and exclusions

**Real-World Applications:** Drug patents and generic medicines, tech patents (smartphones, AI), patent trolls, prior art searches

**Case Studies:** Indian pharmaceutical patents, software patents debate, biotech innovations, green technology patents

---

<div align="center">

### 🎨 Realm 4: Design Domain

<img src="assets/logos/design_logo.png" alt="Design Logo" width="120"/>

**Safeguard Aesthetics**

</div>

Explore the intersection of art and commerce! Learn how unique product designs—from smartphone shapes to furniture aesthetics—are protected under industrial design law.

**What You'll Learn:**
- 🎨 What constitutes a registrable design
- 👁️ Visual appearance vs functional features
- 📋 Design registration process
- ⏰ Protection period (10 years, extendable to 15)
- 🔄 Design vs copyright overlap
- 🌐 Hague Agreement for international designs
- ⚖️ Design infringement and remedies
- 🚫 Exclusions (functional designs, offensive designs)

**Real-World Applications:** Product packaging design, furniture aesthetics, automobile body design, smartphone appearance, fashion design protection

**Examples:** iPhone design patents, Coca-Cola bottle shape, furniture designs, automotive styling

---

<div align="center">

### 🗺️ Realm 5: GI Gateway

<img src="assets/logos/gi_logo.png" alt="GI Logo" width="120"/>

**Celebrate Regional Heritage**

</div>

Journey through India's rich cultural and agricultural heritage! Discover how Geographical Indications protect products unique to specific regions, preserving tradition and supporting local communities.

**What You'll Learn:**
- 🌾 What is a Geographical Indication
- 📍 Link between product quality and origin
- 🏛️ GI registration in India
- 🛡️ Protection against misuse
- 🌍 International GI systems
- 💰 Economic benefits for communities
- ⚖️ Enforcement and penalties
- 🔄 GI vs trademark differences

**Real-World Applications:** Darjeeling Tea, Basmati Rice, Mysore Silk, Kanchipuram Sarees, Alphonso Mango, Kolhapuri Chappals

**Indian GI Products:** 
- 🍵 Darjeeling Tea (West Bengal)
- 🍚 Basmati Rice (Punjab, Haryana)
- 🥭 Alphonso Mango (Maharashtra)
- 🧵 Kanchipuram Silk (Tamil Nadu)
- 👗 Mysore Silk (Karnataka)
- 👞 Kolhapuri Chappals (Maharashtra)
- 🎨 Madhubani Paintings (Bihar)
- And 300+ more registered GI products!

<div align="center">

### 🔐 Realm 6: Trade Secrets Sanctuary

<img src="assets/logos/trade_secrets_logo.png" alt="Trade Secrets Logo" width="120"/>

**Master Confidential Intelligence**

</div>

Unlock the mysteries of business confidentiality! Learn how companies protect their most valuable secrets—from Coca-Cola's formula to Google's search algorithm—without public disclosure.

**What You'll Learn:**
- 🤫 What qualifies as a trade secret
- 🔒 Confidentiality measures and NDAs
- 👥 Employee obligations and non-compete clauses
- ⚖️ Trade secret misappropriation
- 🛡️ Legal protection mechanisms
- 🔄 Trade secrets vs patents (pros and cons)
- 🌐 International trade secret laws
- 💼 Corporate espionage and remedies

**Real-World Applications:** Coca-Cola formula, KFC's 11 herbs and spices, Google's search algorithm, customer databases, manufacturing processes

**Famous Trade Secrets:** Coca-Cola formula (130+ years), KFC recipe, WD-40 formula, Google PageRank algorithm, Listerine formula

### 🛠️ Prerequisites

Before you begin, ensure you have:

- ✅ **Flutter SDK** (3.0 or higher) - [Install Flutter](https://flutter.dev/docs/get-started/install)
- ✅ **Dart SDK** (3.8 or higher) - Comes with Flutter
- ✅ **Android Studio** or **VS Code** - Your preferred IDE
- ✅ **Git** - For version control
- ✅ **Firebase Account** - Free tier is sufficient

### 📥 Installation Steps

**1. Clone the Repository**
```bash
git clone https://github.com/PushkarPisolkar04/iplay.git
cd iplay
```

**2. Install Dependencies**
```bash
flutter pub get
```

**3. Set Up Firebase** 🔥

IPlay uses Firebase for authentication and data sync. You'll need to:

- Create a Firebase project at [console.firebase.google.com](https://console.firebase.google.com)
- Enable **Authentication** (Email/Password + Google Sign-In)
- Create a **Firestore Database** (start in test mode)
- Download configuration files:
  - `google-services.json` → Place in `android/app/`
  - `GoogleService-Info.plist` → Place in `ios/Runner/`
- Run `flutterfire configure` to generate `firebase_options.dart`

**4. Configure Firestore**
```bash
# Deploy security rules
firebase deploy --only firestore:rules

# Deploy indexes
firebase deploy --only firestore:indexes
```

**5. Run the App** 🚀
```bash
# Check connected devices
flutter devices

# Run on connected device
flutter run

# Or run in debug mode
flutter run --debug

# Or build release APK
flutter build apk --release
```

### 🔧 Development Commands

```bash
# Run tests
flutter test

# Check for issues
flutter analyze

# Format code
flutter format .

# Clean build
flutter clean && flutter pub get

# Generate code (if using code generation)
flutter pub run build_runner build --delete-conflicting-outputs
```

./gradlew clean
cd ..
flutter clean
flutter pub get
flutter run

# Solution: Update pods
cd ios
pod install --repo-update
cd ..
flutter run
